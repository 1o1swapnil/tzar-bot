# config/safe-prefixes.txt — operator-maintained allow-list for scope-check.py
#
# Command SEGMENTS whose stripped form starts with any prefix below skip the scope
# check. The command line is split on ; && || | & newlines and substitutions first,
# so `trufflehog x; curl evil.com` still has its curl segment checked.
#
# Local commands (echo, cat, grep, git status, ...) are already recognised by
# tools/scope-check.py; use this file only for tools you trust to never reach an
# out-of-scope host. Prefer config/allowed-hosts.txt when the issue is a host.
#
# Rules:
#   - one prefix per line; matched with str.startswith() against each stripped segment
#   - lines starting with '#' and blank lines are ignored
#   - a trailing space is significant ("nmap " won't match "nmaplike")
#
# Add your own below (examples commented out):
# trufflehog
# gitleaks
# semgrep
# nuclei -update-templates
# terraform plan
# az account show
